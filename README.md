# Capital Analysis of Vietnam's Listed Manufacturing Enterprises

## About

This project examines the capital mobilization and capital utilization of Vietnamese listed manufacturing enterprises, with a focus on their relationship with financial performance.

The study applies quantitative analysis using Python to examine financial data of manufacturing enterprises listed on the Vietnamese stock market during 2015–2023. The analysis includes descriptive analysis, correlation analysis, panel-data regression models, model selection, diagnostic testing, and Generalized Least Squares (GLS) estimation.
