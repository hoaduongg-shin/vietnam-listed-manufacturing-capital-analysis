# Data Documentation

## 1. Data Source

The research dataset consists of financial data of Vietnamese listed manufacturing enterprises covering the period from 2015 to 2023.

The data were extracted from FiinPro-X.

## 2. Research Scope

The dataset covers manufacturing enterprises listed on the following Vietnamese stock exchanges:

- HOSE
- HNX
- UPCoM

The research period covers 2015–2023.

## 3. Data Availability

The raw dataset is not included in this repository due to data access and redistribution restrictions.

The dataset was used for the analysis presented in this research project.

## 4. Variables

The econometric analysis uses two financial performance indicators as dependent variables and five financial indicators as explanatory variables.

| Variable | Full Name | Role in Model |
|---|---|---|
| ROA | Return on Assets | Dependent variable |
| ROE | Return on Equity | Dependent variable |
| AT | Total Asset Turnover | Independent variable |
| D/E | Debt-to-Equity Ratio | Independent variable |
| LIQ | Liquidity | Independent variable |
| SIZE | Firm Size | Independent variable |
| Growth | Firm Growth | Independent variable |

### ROA — Return on Assets

Measures the profitability of the enterprise based on total assets.

### ROE — Return on Equity

Measures the profitability of the enterprise based on shareholders' equity.

### AT — Total Asset Turnover

Measures the efficiency of total asset utilization.

### D/E — Debt-to-Equity Ratio

Measures the relationship between debt and shareholders' equity.

### LIQ — Liquidity

Represents the liquidity position of the enterprise.

### SIZE — Firm Size

Represents the size of the enterprise.

### Growth — Firm Growth

Represents the growth rate of the enterprise.

For the detailed measurement formulas and definitions of the variables, please refer to the research report and [`PROJECT_OVERVIEW.md`](../PROJECT_OVERVIEW.md).
